# Project 4 - Load Balancer Simulation

Author: Rahul Ravi
Course: Cloud Computing
Language: C++

## Overview

This project simulates a load balancer that manages
incoming web requests using multiple web servers.

The simulation will use a queue to store requests
and distribute them to available web servers.

## Planned Features

- Random request generation
- Request queue
- Multiple web servers
- Dynamic server allocation
- IP range blocking
- Configurable simulation settings
- Verbose and quiet logging
- Simulation statistics

## Project Status

Initial project setup and design phase.

## Design

The system will include Request, WebServer,
LoadBalancer, and IPFirewall components.

The main-program workflow and function interfaces
will be designed before implementation.
